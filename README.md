# QSkill Internship – Python Development

## Selected Slab: Slab 2 (Intermediate)

I have selected **Slab 2 – Intermediate** for the QSkill Python Development internship.

The projects included in this slab are:

1. **Voice-Activated Personal Assistant** – A Python assistant that supports voice commands, reminders, weather updates, news headlines and text-to-speech.
2. **Sentiment Analysis Web Application** – A Django application that classifies text as positive, negative or neutral using TextBlob.
3. **Gemini Conversational AI** – A Python application with conversation history and Google Search integration for current information.
4. **Speech-to-Image Generation** – A Streamlit application that converts spoken input into text and generates an image using the Stability AI API.

**Technology used:** Python, Django, Streamlit, TextBlob, Gemini API, SpeechRecognition and Stability AI.

This repository contains my implementations of the Slab 2 tasks.
